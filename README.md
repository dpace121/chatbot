🤖 Grok Chatbot App

A full-stack AI chatbot application built using React (Frontend) and Node.js (Backend), powered by the Grok API model. This app allows users to ask questions and receive AI-generated responses in real time.

🚀 Features
💬 Ask anything using a simple UI
⚡ Real-time AI responses using Grok API
🧠 Markdown support for formatted answers
🎨 Clean and responsive UI with Tailwind CSS
🔄 Loading state handling
🛠️ Tech Stack
Frontend
React.js
Axios
React Markdown
Tailwind CSS
Backend
Node.js
Express.js
Grok API (AI Model)
